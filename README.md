# Minecraft Beta Advanced

A custom fork of Minecraft Beta 1.8 that expands Adventure Update-era gameplay with new biomes, blocks, movement changes, creative improvements, and worldgen options.

## Version
Current release: `R1.2`

## Features
- Sprinting with stamina
- Expanded creative inventory
- Custom world generation options and presets
- New biome: Shrublands
- New wood sets: Cattaiga and Calypse
- New stone set: Marble

## Installation

### MultiMC
1. Create a `Beta 1.8` instance
2. Edit Instance
3. Version
4. Replace `minecraft.jar`
5. Select `BetaAdvancedR1.0-standalone.jar`
